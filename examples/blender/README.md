# Blender Live & Procedural Examples

Production-ready scripts demonstrating real-time interactive Blender control and procedural WebGL asset production.

## Files
- `procedural_gem.py`: Procedural emerald gemstone with PBR transmission glass shaders and 360-degree turntable animation.
- `live_blender_demo.py`: Python script that auto-detects a live Blender session (or falls back to headless), builds the asset, and exports a Draco-compressed `.glb`.

## Testing the Demo
```bash
python3 examples/blender/live_blender_demo.py
```
