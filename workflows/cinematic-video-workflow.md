# Workflow: Cinematic Video Production Pipeline

## Overview
A production pipeline for programmatic video rendering using Remotion, audio design, and FFmpeg.

```
[1. Script & Beat Sheet]  ──► Audio hit points, vocal script, visual shot list.
[2. Visual Design]        ──► Figma / Vector frame designs, 3D asset generation.
[3. Remotion Composition] ──► Component structure, Sequences, interpolate/spring choreographies.
[4. Audio Mastering]      ──► Music bed synchronization, ducking, whoosh/impact placement.
[5. Look Development]     ──► Color grading curves, film grain passes, vignette.
[6. Render & QC]          ──► Remotion CLI render (`npx remotion render`), bitstream audit.
```
