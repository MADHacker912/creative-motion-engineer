# Checklist: Real-Time 3D Quality
- [ ] Mesh triangle counts within budget (<50k mobile, <150k desktop).
- [ ] Textures compressed with KTX2 / Basis or optimized WebP.
- [ ] Draw calls kept below 50 on mobile.
- [ ] Lighting verified: Key, Fill, Rim and ambient HDRI reflections.
- [ ] Memory disposal functions registered for all geometries and materials.
