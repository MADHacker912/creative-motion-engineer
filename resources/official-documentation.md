# Official Documentation & Technical Specifications

When implementing creative motion code, official technical documentation takes absolute precedence over random tutorials.

## 1. Web Motion & UI Animation
- **GSAP (GreenSock)**: https://gsap.com/docs/v3/
  - ScrollTrigger: https://gsap.com/docs/v3/Plugins/ScrollTrigger/
  - Flip Plugin: https://gsap.com/docs/v3/Plugins/Flip/
  - Observer Plugin: https://gsap.com/docs/v3/Plugins/Observer/
- **Motion (formerly Framer Motion)**: https://motion.dev/
- **Lenis Smooth Scroll**: https://github.com/darkroomengineering/lenis
- **W3C Web Animations API (WAAPI)**: https://www.w3.org/TR/web-animations-1/
- **CSS Transitions & Transforms**: https://www.w3.org/TR/css-transforms-1/

- **Three.js Examples**: https://threejs.org/examples/
- **React Three Fiber (R3F)**: https://r3f.docs.pmnd.rs/
- **Drei Helpers**: https://github.com/pmndrs/drei
- **WebGL 2.0 Specification**: https://registry.khronos.org/webgl/specs/latest/2.0/
- **The Book of Shaders**: https://thebookofshaders.com/
- **Khronos glTF 2.0 Specification**: https://www.khronos.org/gltf/
