# Learning Roadmap: Becoming a Creative Motion Engineer

## Phase 1: Creative & Visual Foundations (Weeks 1-4)
- Master the 12 Principles of Animation and their digital screen equivalents.
- Study composition, dynamic symmetry, negative space, and typographic hierarchy.
- Learn color theory, value contrast, and lighting physics (key/fill/rim).

## Phase 2: Web Motion Architecture (Weeks 5-8)
- Master GPU-accelerated CSS properties (`transform`, `opacity`) and cubic bezier curves.
- Master GSAP 3: Master timelines, relative positional syntax, and label orchestration.
- Build responsive scroll storytelling using GSAP ScrollTrigger and Lenis smooth scroll.
- Learn layout morphing with the FLIP technique and React `useGSAP`.

## Phase 3: Real-Time 3D & WebGL (Weeks 9-14)
- Understand the 3D pipeline: meshes, vertex buffers, UV mapping, and PBR shaders.
- Master Three.js scene graphs, camera rigs, and memory disposal patterns.
- Transition to React Three Fiber (R3F) and Drei helpers.
- Write custom GLSL vertex and fragment shaders (procedural noise, chromatic aberration, post-processing).

## Phase 4: Programmatic Video & Audio Design (Weeks 15-18)
- Learn Remotion: compositions, sequences, frame interpolation, and spring physics.
- Master sound design: transient alignment, audio ducking, risers, and impact hits.
- Build automated FFmpeg video encoding pipelines (two-pass MP4, transparent WebM).

## Phase 5: Production Mastery & Optimization (Weeks 19+)
- Profile frame times in Chrome DevTools to eliminate layout thrashing.
- Optimize 3D scenes: draw calls, InstancedMesh, and texture compression (KTX2/Draco).
- Ensure 100% compliance with `prefers-reduced-motion` and WCAG 2.1 AA.
