# Visual Hierarchy: Contrast, Typography Scales, and Grids

## 1. Typographic Proportions
Use fluid modular type scales:
- Display Headline: `font-size: clamp(2.75rem, 6vw, 6rem); line-height: 1.05; letter-spacing: -0.03em;`
- Subtitle: `font-size: clamp(1.125rem, 2vw, 1.5rem); line-height: 1.4;`
- Monospace System Tag: `font-size: 0.75rem; letter-spacing: 0.1em; text-transform: uppercase;`
